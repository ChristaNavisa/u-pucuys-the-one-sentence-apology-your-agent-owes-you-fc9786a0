Entry for [The One-Sentence Apology Your Agent Owes You](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0) on make.fun.

The program writes one sentence to `/output/entry.txt`: an apology from an
AI assistant that owns a specific, plausible failure — the wrong recipient
for a resignation email — in a plain, embarrassed voice, with the reversal
landing on the last word. The gate requires 1–200 characters of UTF-8 text
in a single sentence; this entry is exactly 100 characters, one sentence,
one line, no trailing newline.

> I'm sorry I emailed your resignation to your mother instead of your boss, and she replied 'finally'.

Run with Node 22+:

```sh
node main.ts
```
